Energy Agent · GPKE

A tool-calling agent for German electricity market processes (supplier switch, supply start/end, default supply). It searches the BNetzA GPKE documents, computes process deadlines in German working days and looks up switch requests in a test database.

How it works

  • RAG: GPKE parts 1, 2, 4 and decision BK6-22-024 (231 pages) are chunked by section, embedded locally with bge-m3 and searched in PostgreSQL/pgvector (vector + German full-text).
  • Tools: search_documents, calculate_deadline (rule table from GPKE part 2, working days incl. all state holidays, 24.12./31.12.), get_switch_status (fictional test data).
  • Loop: plain tool-calling loop, provider-agnostic (Mistral API or Ollama), with a guardrail that rejects answers given before any tool result.
  • Evaluation: 29 golden questions with deterministic checks: Mistral 86–90 %, the same model locally 79 %.
